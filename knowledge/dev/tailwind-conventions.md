# Convenções de Estilização Tailwind CSS

## Design Tokens e Paleta de Cores
Utilize tokens semânticos (`primary`, `secondary`, `muted`, `accent`) configurados no `tailwind.config.ts`.
Evite cores literais arbitrárias para manter consistência temática.

## Layout Responsivo e Viewport Mobile
Adote abordagem mobile-first: defina classes base para mobile (375px) e use prefixos (`sm:`, `md:`, `lg:`) para telas maiores.
Garantir contrastes acessíveis conforme diretrizes WCAG AA.
