# Browser Automation Gateway (Port :3014)

Automated browser and testing microservice:

- High-resolution viewport screenshot capture (desktop 1280x800, mobile 375x812 DPR 3 for WhatsApp)
- Browser console error and network inspection
- Resilient UI interactions (click, fill, wait)
- E2E testing execution
- Native MCP Server exposing tools
