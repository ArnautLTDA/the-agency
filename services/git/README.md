# Git & GitHub VCS Gateway (:3011)

Official Git and GitHub VCS microservice and MCP server for The Agency software house.

Exposes:
- `git_init_repository`
- `git_create_branch`
- `git_commit`
- `git_get_diff`
- `git_get_status`
- `github_create_repo`
- `github_push`
- `github_create_pull_request`
